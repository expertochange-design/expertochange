# Drafts

Work that is not on the site yet. Nothing in this folder is built or published.

- `seven-habits/` holds the full video scripts for the 7 Habits series (English and Farsi).
  The live posts show a short "stay tuned" note (`comingSoon: true`) until each final video
  is released, one part per week. To release a part, put its final text back into
  `src/content/books/<lang>/<same file name>`, add the video, and remove `comingSoon: true`.
